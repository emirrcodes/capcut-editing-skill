# v0.6.0 validation

- 129 automated tests passed locally on Apple Silicon with Python 3.13 and FFmpeg. Test directories/logs are retained outside the repository. The skill format validator and git diff --check passed.
- Tight defaults remain unchanged: amplitude silence at -30 dB / 80 ms; speech gaps at 80 ms with 30 ms padding and word, whole-timeline pause and source verification enabled. Explicit natural-pause settings remain available.
- New speech regressions protect a 560 ms weak word corroborated by a second stretched context, without restoring that context’s long noise interval. Duplicate contexts, different word occurrences, cropped boundaries and uncertain decodes cannot corroborate. Integration verifies the context guard restores speech omitted by base VAD before additional pause cutting.
- Source verification rejects independently protected prefix loss even when candidate ASR recognizes the same token and VAD detects no speech there. Existing VAD protection, source ordering, repetitions, false starts, user-reviewed overrides and 100 ms output-clip guards remain tested.
- New subtitle regressions require independent review for 253 ms/300 ms early crossing words instead of silently keeping early captions. The 250 ms alignment rule and true continuing left speech remain tested.
- Caption preparation generates hashed independent context/clip reviews for stretched and multi-cut word times. Preview/apply rejects unresolved flags before backup/project writes. Tests cover supported repeat restoration, updated indexes, a confirmed slow word bound to generated evidence, note-only rejection and modified-audio rejection. No extra audio review runs for unflagged captions.
- Saved-only word-payload overflow within one known frame is reported; fresh raw validation remains strict and larger overflow is rejected. Existing two-way clip ownership checks remain independent of frame uncertainty and gapless coverage.
- Successful apply keeps diagnostic evidence after managed work cleanup. Tests verify an unavailable diagnostic destination stops before project writes. Backups, rollback, mirror consistency, mtime-only changes, material references, target-project closure and portable installation remain covered.
- Changes were prompted by an independent installed-agent trial and a read-only audit of native-resaved draft data. The new version has been tested on synthetic projects; it has not been applied to that personal project or independently retested by another agent. Automated checks do not prove semantic ownership or exact phoneme boundaries for every recording.
- Personal projects, media, transcripts, backups, reports, model weights and test temporaries are excluded from this repository. GitHub Actions targets macOS, Windows and Linux; local results do not establish remote CI success or native Windows CapCut compatibility. Native Windows round-trip validation remains pending.
