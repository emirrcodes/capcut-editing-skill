# v0.5.0 validation

- 111 automated tests passed locally on Apple Silicon with Python 3.12 and FFmpeg. The suite covers the portable installer, draft backups and rollback, material references, mirror consistency, subtitle formatting, audio alignment, and speech protection.
- Tight pacing is now the code default for both commands: amplitude silence starts at 80 ms; speech cutting uses 80 ms gaps, 30 ms padding and all word/pause/source checks. An explicit natural-pause profile preserves the previous pacing thresholds while keeping speech checks enabled.
- New default-command tests show real FFmpeg removes a 120 ms silent pause that the natural profile keeps; default speech preparation runs word review, whole-timeline pause review and actual source verification without adding captions. Missing transcription stops without amplitude fallback or project writes. Effective cut settings are reported through preparation/preview/apply.
- New speech regressions cover stretched word timestamps, short/weak words, whole-timeline pause review, source-range preservation despite recognition differences, hash-bound user-reviewed gaps, and the distinction between the 80 ms pause threshold and 100 ms output-clip minimum.
- New subtitle regressions reject gapless captions that cross into the wrong clip. They cover both early right words and late right words after a cut, same-clip gaps, continuous speech, ambiguous multiple cuts, strict raw-word validation, and bounded saved-word frame uncertainty.
- Transcript review preserves the original transcript and evidence, rejects stale hashes and changes outside reviewed ranges, and never writes the CapCut project. Review archives survive normal work cleanup.
- Write regressions cover target-project closure while CapCut may remain open, file hash/size checks, mtime-only changes, backup integrity, and post-write checks with fresh raw subtitle words.
- The v0.4.0 implementation and the same tight speech profile were previously applied to a local noisy Turkish talking-head timeline and then used to add native editable subtitles. Saved draft data passed both raw-word and saved-payload boundary checks; video segments, source ranges, other tracks, and duration were preserved during subtitle insertion. Personal projects, media, transcripts, backups, reports, model weights, and test-run temporary files are excluded from this repository.
- The updated v0.5.0 default commands have been tested on synthetic projects; an independent agent test of these new defaults and native CapCut reopen/resave validation remain pending. Automated tests and disk validation do not prove semantic ownership or exact phoneme boundaries for every recording.
- The GitHub Actions matrix targets macOS, Windows, and Linux. Check this commit's workflow result; local test results do not establish remote CI success or native Windows CapCut compatibility. Native Windows round-trip validation remains pending.
